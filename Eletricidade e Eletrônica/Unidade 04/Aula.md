# Circuitos Elétricos

## Associação de Resistores

### Serie

* Um circuito com resistores associados em serie possuirá apenas um caminho para a corrente passar, onde ela será constante em todo caminho.

    * I = I1 = I2 = I3 = ...

* A resistência equivalente será a soma de todos os resistores.
  
    * R = R1 + R2 + R3 + ...   

* Cada resistor estará submetido a uma tensão, ou seja, haverá uma queda de tensão em cada resistor, e a tensão equivalente será a soma de todas as tensões.

    * V = V1 + V2 + V3 + ...

### Paralelo

* Um circuito em paralelo dispoe de dois ou mais caminhos para a corrente passar, fazendo com que ela se divida.

* A quantidade de corrente para cada resistor será inversamente proporcional à resistência, ou seja, o menor resistor terá a maior corrente.

   * I = I1 + I2 + I3 + ...

 * A tensão será a mesma do inicio ao fim.
 
   * V = V1 = V2 = V3 = ...
  
* Quando houver apenas dois resistores, a resistência equivalente será = R1 * R2 / R1 + R2.

* Quando todos os resistores forem iguais, a resistência equivalente será = R / número de resistores.

* Nos demais casos = 1 / R1 + 1 / R2 + 1 / R3 + ...

## Leis de Kirchhoff

* Para circuitos mais complexos, acaba sendo inviável utilizar a Lei de Ohm, então para lidar com isso existem as Leis de Kirchoff.

* Antes de entender a Lei de Kirchoff, é importante entender três conceitos fundamentais para a formação de uma rede elétrica.

* **Nó** é um ponto no qual são conectados dois ou mais condutores, ou seja, é um ponto que divide a corrente elétrica.

* **Ramo** é um trecho do circuito compreendido em entre dois nós consecutivos.

*  **Malha** é um conjunto de ramos que formam um percurso fechado.

*  Para fins de cálculo, é necessário definir um sentido para a corrente, sentido que pode estar correto ou não.

### Leis dos nós

* A soma das correntes em um nó é nula, ou seja, a soma das correntes que entram é igual à corrente que sai.

### Lei das malhas

* A soma das tensões de uma malha é nula, ou seja, se eu tiver mais de uma fonte de tensão em uma malha a soma será nula.

   * Ex: Se numa malha eu tiver resistores, haverá queda de tensão ou seja, eu terei novos valores de tensão nessa malha, a soma de todas as tensões dela será nula.
