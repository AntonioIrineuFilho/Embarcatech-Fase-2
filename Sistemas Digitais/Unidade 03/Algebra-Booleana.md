# Insights

## Associativa x Comutativa

* Se todas as variáveis tiverem o mesmo símbolo(+ ou .), pode-se remover os parênteses:

  * Ex: A + (B + C) = A + B + C

* Se houver simbolos diferentes, deve-se distribuir:

  * Ex: A . (B + C) = A . B + A . C

* **NÃO CONFUNDIR COM ABSORÇÃO, A COMUTATIVA É FEITA COM MAIS DE DUAS VARIÁVEIS, QUANDO HÁ APENAS DUAS É ABSORÇÃO**

## Absorção

* Quando houver duas várias em um cenário semelhante a uma comutativa, deixa apenas o primeiro bit:

  * Ex: A . (A + B) = A | A + (A . B) = A

 ## De Morgan

 * De Morgan vale para os dois tipos, tanto (A + B)' quanto (A . B)':

   * (A + B)' = A' . B' | (A . B)' = A' + B'
